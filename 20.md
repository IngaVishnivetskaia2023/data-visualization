## Bar Chart

❗You SHOULD START AT ZERO VALUE

For this data we cannot use Line Chart, because Bars represent **different Categories**.
The data between them is NOT correlated at all.

A bar chart (or bar graph) is a data visualization tool that represents categorical data using rectangular bars, 
where the lengths or heights are proportional to the values they represent. 
It is primarily used to compare different groups, analyze trends, or track changes over time, with bars plotted vertically or horizontally.
